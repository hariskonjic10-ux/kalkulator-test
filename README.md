# Kalkulator - testni projekt

Testni projekt za 1. vajo pri predmetu Razvoj programske opreme.

## Funkcionalnost

- Osnovne aritmetične operacije: seštevanje, odštevanje, množenje in modulo.
- Samodejno testiranje s pomočjo GitHub Actions.
- Uporaba Git-a za upravljanje različic in vej.

## Tehnologije

- Jezik: C++
- Verzijska kontrola: Git
- CI/CD: GitHub Actions

## Zagon projekta

1. Kloniranje repozitorija:

   `git clone git@github.com:VAŠ-USERNAME/kalkulator-test.git`

2. Prevajanje programa:

   `g++ -o kalkulator kalkulator.cpp`

3. Zagon programa:

   `./kalkulator`
